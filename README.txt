# Formula Factor Championship — web

Web estática lista para publicar con GitHub Pages o Cloudflare Pages.

Archivos:
- index.html — contenido de la web
- style.css — diseño
- script.js — cuenta atrás

Para personalizar:
1. Cambia textos, pilotos y circuitos en index.html.
2. Cambia la fecha de la próxima carrera en script.js.
3. Sustituye los enlaces `#` de Discord/inscripción/reglamento por tus enlaces reales.

La web no necesita servidor ni base de datos para esta primera versión.
